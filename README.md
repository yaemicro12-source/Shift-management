# Shift-management
実務経験に基づいたシフト管理Webアプリケーションの作成

共通ページ
    ・全体シフト
    ・個人シフト
    ・メッセージ画面

従業員サイドページ
０：ログインページ
        ・ID
        ・パスワード
        ・管理者ログインはこちら
１：メイン画面
        ・個人シフト
        ・全体シフト(権限次第)
        ・シフト提出
        ・ログアウトボタン


２：個人シフト
        ・自分のシフトがカレンダー形式で確認可能
        ・今日が色付き
        ・管理者の設定した時間枠と色で表示。見間違えを減らす
        ・タスク入力も可能  
        ・タップで休憩時間の確認も可能

３：全体シフト(権限次第)
        ・全(エリア内)スタッフのシフト確認が可能
        ・当日は色付ける
４：シフト提出
        ・表形式かつチェックシート方式
        ・スタッフによって○×の選択が可能
        ・可能時間帯、可能枠を管理者が設定してチェックボックスとしておいておくことも可能⇒時間帯を参照してシフト計算が可能
        ・トータルの日数が契約より少ない場合、警告メッセージを出す
        ・各日メモを入れることも可能(日付を引っ張ってきてメッセージを送ることも可能)
        ・スタッフによって管理者と同じように不足枠を確認も管理者権限で可能

管理者サイドページ
１：管理者ログインページ
    ・ID
    ・パスワード
    ・エリアコード
    ・オーナーログインはこちら
２：メイン画面
    ・シフト作成・変更
    ・シフト設定
        （入力欄・個人・シフト）
    ・シフト提出
    ・シフト確認
    ・スタッフ一覧・編集
    ・メッセージ
    ・ログアウト

３：シフト作成 
    ・○年○月のシフトを作成します（ドロップダウン）
        →作成完了しました→確認する
    ・作成済みのシフトを編集する
    ・変更
        →変更日時を入力して組みなおしボタン
        or手入力も可能(作成済みシフト編集ページへ)

４：作成済みシフト編集
    ・シフト未提出者の表示→ボタンからメッセージに催促テンプレ一斉送信
    ・時間の横グラフの形になっている
    ・入っている時間と名前が表示される
    ・不足枠が表示される（黄色）（自分のシフトを組むボタンを押しても賄えない場合は赤）
    ・右上に＋ボタン
        →別ウィンドで小さく○月○日スタッフ名（ドロップダウン）送信
        →指定箇所にシフトを増やせる
    ・ドロップ＆ドラックで時間を延ばしたり減らしたりシフト交換ができるとベスト
        →難しければ、スタッフ名クリックで別ウィンド開いて編集
    ・１作業戻るボタン
    ・スタッフを選択すると選択したスタッフのみ色がついた一覧が見れる

５：シフト設定
    ・入力欄
        ・時間帯指定枠チェック項目作成
        ・時間帯自由記入許可（個別に設定することも可能）
    
    ・個人設定
        ・スタッフを選択
            ・入れない時間（★）
            ・週・月のMax時間（★）
            ・一緒に入れないスタッフ
            ・優先的に入れる枠・曜日
                →シフト設定で設定した枠を表示
            ・シフトの○×設定
            ・警告メッセージの最低日数・有無
            ・全体シフトの閲覧権限☐
            ・不足枠の表示☐
            ・役職者☐
                →被らないように配置
            ・配属店舗(複数チェック可能)
            ・研修生☐
            　→試用期間を設定→管理者のシフトに表示
            ・終電時間（★）
            ・時給入力(ランク分けして紐づけも可能)
            ・希望勤務時間(★)


            ★は従業員に入力依頼が可能
            
    ・シフト設定
        ・必要枠の入力
        ・曜日ごとに設定（設定した必要を時間グラフ見ながら増減ができる）
        ・予備枠の追加（人員に余裕がある時の枠設定）
        ・平日の祝日（通常平日・金曜日・月曜日）などのパターンを作成
        →条件に当てはまる場合シフト作成時に適用させるか確認
        ・条件に当てはまらない日があった場合確認（）エラー文＋色変える
        ・人が少ない日のパターンも作成しておくと自動適応
        ・店舗や時間枠の色設定

６：シフト提出
        ・Max時間を入れて、不足枠に配置するボタン
        ・手で組むことも可能(シフト編集ページと同じ)
        ・スタッフの提出方法でくむのも可能

７：シフト確認(スタッフ用とほとんど同じ)
        ・タスク入力が自由
        ・店舗での表示・エリア全体の表示での切り替えが可能
        ・人件費の表示も可能
        ・スタッフの希望時間と稼働時間の表示
            →極端に差がある場合色付ける(タップで該当スタッフに色がついた編集ページ表示)

        
８：スタッフ一覧・編集
    ・スタッフ一覧
        ・入力済みの個人設定確認(編集ページへ遷移も可)
        ・月のトータル勤務時間確認
    ・スタッフ編集
        ・スタッフの追加
            →リンク＋QRコードを表示して新規登録
            →リンク先はID・パスワード・エリアの設定
        ・スタッフの削除
        ・スタッフのシフト優先順位とメモ
        （入力しないことも可能）
９：店舗編集
    ・店舗の追加・削除
    ・店舗の編集
        ・店舗の営業時間の変更が可能（一括）
        ・カレンダーから選択してピンポイントに変更も可能
    ・売上入力でシフト確認ページに人件費の割合が確認できる


１０：メッセージ
    ・スタッフにワンボタンでシフト提出催促・シフト変更依頼が可能
    ・スタッフ側からのメッセージは認証制

オーナーサイドページ
１：全スタッフのID・パスワードの確認・検索
２：管理者に１の管理権限を与える
３：管理者の招待
４：エリア設定
    ・エリア追加・削除
    ・店舗追加・削除
    ・エリアコード一覧
５：各店舗の人件費確認
６：時給設定
    ・ランク分けと時給設定
